# 🌦️ Advanced Weather Forecast Web App

A feature-rich, real-time **Weather Forecast Web Application** built using HTML, CSS, and JavaScript.  
This project integrates external weather APIs to provide live weather updates, hourly forecasts, and 5-day predictions with an interactive and animated UI.

## 🌐 Live Demo
👉 https://your-username.github.io/your-repo-name/

## 📌 Project Overview

This application allows users to search any city worldwide and view real-time weather conditions including temperature, humidity, wind speed, visibility, sunrise/sunset timing, and extended forecasts.

It also includes advanced features like:
- Favorites system using localStorage
- Hourly + 5-day forecast visualization
- Dynamic UI animations
- Unit conversion (°C / °F)

## 🚀 Features

### 🌍 Core Features
- Live weather data by city search
- Real-time temperature, humidity, pressure, wind, visibility
- Weather condition icons with dynamic updates

### 📊 Forecasting System
- ⏱️ Hourly forecast (next 24 hours)
- 📅 5-day weather forecast
- Min/Max temperature tracking per day

### ⭐ Advanced Features
- 💾 Save favorite cities (localStorage)
- 🔁 Toggle between Celsius and Fahrenheit
- 🌅 Sunrise & Sunset live countdown
- 🎨 Dynamic background changes based on weather
- ✨ Smooth animations using GSAP
- ❌ Error handling for invalid cities

## ⚙️ How It Works

1. User enters a city name  
2. API request is sent to OpenWeatherMap  
3. JSON response is processed  
4. UI updates dynamically with weather data  
5. Forecast and hourly data are rendered  
6. Data is stored (favorites system) if saved
